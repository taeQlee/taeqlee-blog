## Core Mental Model

**Context는 한 번의 LLM inference에서 모델에게 실제로 제공되는 token sequence이고, context window는 그 sequence를 얼마나 길게 다룰 수 있는지를 나타내는 범위/제약이다.** Application이 conversation history, RAG 검색 결과, system instruction 등을 모아 context를 만들고 tokenizer가 이를 token ID buffer로 변환한다. Transformer 내부에서는 문자열 자체를 저장해서 검색하는 것이 아니라 token representation과 attention을 계산하며, autoregressive inference 중에는 이전 token의 Key/Value tensor가 **KV cache라는 실제 RAM/VRAM 자료구조**에 저장된다. 따라서 **RAG/Memory는 context가 아니며, 필요한 외부 정보를 골라 현재 context에 넣어주는 상위 시스템**이라고 구분하면 된다.
